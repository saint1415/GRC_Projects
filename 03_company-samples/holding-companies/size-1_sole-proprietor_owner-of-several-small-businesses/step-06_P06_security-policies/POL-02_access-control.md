At the Sole Proprietorship tier the business keeps **one** consolidated policy for all four entities, because one person writes, follows, and checks it (`01_company-sizes/tier-project-scaling.csv`, t1 P06). This file is kept so the folder has the standard policy set names. It holds no separate rules.

**Where the access control rules are:**

- POL-01 section 7 (Access control): own accounts and PINs, no shared passwords (7.1), app-based MFA and hardware keys (7.2), password manager and default passwords (7.3), hire and departure checklist and quarterly review (7.4), least privilege for the bookkeeper and a separate administrator account (7.5), device lock (7.6), monthly review (7.7), sealed emergency access (7.8).
- POL-01 section 6.6: owner-started, watched remote support sessions.
- POL-01 section 9.4: only the owner changes payees.
- SP 800-53 AC-1 and IA-1 (policy and procedures) are met by POL-01 as a whole.

Traceability for every statement is in `policy-control-map.csv`.
