At the Sole Proprietorship tier the inn keeps **one** consolidated policy, because one person writes, follows, and checks it (`01_company-sizes/tier-project-scaling.csv`, t1 P06). This file is kept so the folder has the standard policy set names. It holds no separate rules.

**Where the access control rules are:**

- POL-01 section 7 (Access control and monitoring): own account for every person (7.1), MFA everywhere it is offered (7.2), password manager and no saved browser passwords (7.3), front desk role and quarterly user review (7.4), device lock (7.5), sealed emergency access codes (7.6), monthly log review (7.7), monthly website check (7.8), master door code changes (7.9).
- POL-01 sections 6.4 and 6.5: owner-started remote support sessions; quarterly review of lock and router app accounts.
- SP 800-53 AC-1 and IA-1 (policy and procedures) and PCI DSS Requirements 7.1 and 8.1 (documented processes and roles) are met by POL-01 as a whole.

Traceability for every statement is in `policy-control-map.csv`.
