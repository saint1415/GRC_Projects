At the Sole Proprietorship tier the adviser keeps **one** consolidated policy, because one person writes, follows, and checks it (`01_company-sizes/tier-project-scaling.csv`, t1 P06). The FTC Safeguards Rule allows the written program to be "in one or more readily accessible parts" (16 CFR 314.3(a)). This file is kept so the folder has the standard policy set names. It holds no separate rules.

**Where the data classification and handling rules are:**

- POL-01 section 8 (Data handling): three classification levels (8.1), approved storage locations (8.2), encryption (8.3), secure sharing instead of attachments (8.4), backups (8.5), books and records (8.6), disposal (8.7), two-year deletion of former-client data unless required (8.8), retention of security documentation (8.9).
- POL-01 Appendix A: data locations, vendors, and records index.
- SP 800-53 MP-1 and SC-1 are met by POL-01 as a whole.

Traceability for every statement is in `policy-control-map.csv`.
