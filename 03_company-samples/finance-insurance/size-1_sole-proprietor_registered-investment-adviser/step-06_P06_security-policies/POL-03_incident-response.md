At the Sole Proprietorship tier the adviser keeps **one** consolidated policy, because one person writes, follows, and checks it (`01_company-sizes/tier-project-scaling.csv`, t1 P06). The FTC Safeguards Rule allows the written program to be "in one or more readily accessible parts" (16 CFR 314.3(a)). This file is kept so the folder has the standard policy set names. It holds no separate rules.

**Where the incident response rules are:**

- POL-01 section 10 (Incident response): runbook and printed contacts (10.1), same-day incident log with discovery time (10.2), custodian fraud line first (10.3), notification deadlines (10.4), ransom decisions (10.5), annual walkthrough and lessons learned (10.6).
- The procedure itself is the P08 runbook (`../step-08_P08_incident-response-runbook/ir-runbook.md`) and its notification matrix.
- A written incident response plan is not required at this size (16 CFR 314.6 exempts 314.4(h)); the adviser keeps one because Florida's 30-day notice clock needs it.
- SP 800-53 IR-1 is met by POL-01 as a whole.

Traceability for every statement is in `policy-control-map.csv`.
