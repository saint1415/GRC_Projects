At the Micro tier the railroad keeps three core policies. The workforce use rules that an Acceptable Use Policy would hold are short enough to sit with the access rules employees already read, so they live in **POL-02 Part C. Workforce use rules**, with the AI tool rule in POL-04:

| Essential rule | Where it lives |
|---|---|
| Use company systems for company work | POL-02 C.1 |
| No Restricted information in personal email, personal cloud storage, messaging apps, or public AI chatbots | POL-02 C.2 |
| Approved AI tools only; the track defect detection pilot only under the P10 conditions | POL-04 4.7 |
| Lock screens; never share passwords or MFA codes; never approve an MFA prompt you did not start | POL-02 C.3 |
| Security awareness training at hire and yearly; phishing simulations | POL-02 C.4 |
| Report suspected incidents at once; tell the dispatcher about anything affecting dispatch | POL-02 C.5 and POL-03 4.2 |
| Confirm any payment or bank detail change by phone using a number on file | POL-02 C.6 |
| Signed acknowledgment at hire and after each annual update | POL-02 C.7 |

Traceability for these rules is in `policy-control-map.csv` under POL-02 and POL-04.
