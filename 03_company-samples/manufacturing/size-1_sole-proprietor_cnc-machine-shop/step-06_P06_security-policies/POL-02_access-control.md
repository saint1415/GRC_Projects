At the Sole Proprietorship tier the shop keeps **one** consolidated policy, because one person writes, follows, and checks it (`01_company-sizes/tier-project-scaling.csv`, t1 P06). This file is kept so the folder has the standard policy set names. It holds no separate rules.

**Where the access control rules are:**

- POL-01 section 7 (Access control): unique accounts (7.1), standard user account for daily work (7.2), MFA (7.3), passwords and default passwords (7.4), account approval, removal, and quarterly review (7.5), device lock (7.6), emergency access (7.7), monthly sign-in and device review (7.8).
- POL-01 6.5: owner-started, watched remote support sessions.
- POL-01 9.3 and 9.5: network separation and physical access (visitor log, escort, keys).
- SP 800-53 AC-1 and IA-1 (policy and procedures) are met by POL-01 as a whole. Rules tagged [FAR] carry FAR 52.204-21(b)(1)(i), (ii), (v), (vi), (viii), and (ix).
