At the Micro tier the company keeps three core policies: access control (POL-02), incident response (POL-03), and data classification (POL-04). A separate Information Security Policy would add little for 7 people, so its essential rules live in **POL-02 Part A. Program governance**. Together with POL-03, POL-04, and the SSP (P02), they form the written information security program both bank contracts expect.
