At the Sole Proprietorship tier the practice keeps **one** consolidated policy, because one person writes, follows, and checks it (`01_company-sizes/tier-project-scaling.csv`, t1 P06). This file is kept so the folder has the standard policy set names. It holds no separate rules.

**Where the access control rules are:**

- POL-01 section 7 (Access control): named accounts (7.1), MFA everywhere it is offered and written approval of any alternative (7.2), password manager and no stored passwords (7.3), helper accounts and quarterly tax software user review (7.4), device lock (7.5), sealed emergency access (7.6), monthly and filing-season log and EFIN/PTIN review (7.7), security change log (7.8).
- POL-01 sections 6.5 and 6.6: IRC 6713 and 7216 notice to contractors before access; owner-started, watched remote support with MFA on the contractor's account.
- SP 800-53 AC-1 and IA-1 (policy and procedures) are met by POL-01 as a whole.
