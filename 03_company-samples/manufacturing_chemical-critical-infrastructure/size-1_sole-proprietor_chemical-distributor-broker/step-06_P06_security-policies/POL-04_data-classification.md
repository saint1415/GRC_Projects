At the Sole Proprietorship tier the business keeps **one** consolidated policy, because one person writes, follows, and checks it (`01_company-sizes/tier-project-scaling.csv`, t1 P06). The hazmat transportation security plan (HSP-01) is a separate document only because 49 CFR 172.802 requires a written plan that can be shown to DOT or DHS. This file is kept so the folder has the standard policy set names. It holds no separate rules.

**Where the data classification and handling rules are:**

- POL-01 section 8 (Data handling): three classification levels (8.1), BOLs only from the product description sheet (8.2), encryption (8.3), monthly backup and quarterly restore test (8.4), retention schedule for BOLs, registration and training records, and driver data (8.5), deletion and device wipe (8.6), no collection of full license numbers (8.7).
- POL-01 Appendix A: where Restricted data may be kept.
- POL-01 section 6.3: the new-product rule for the Hazardous Materials Table check and ERI registration.
- SP 800-53 MP-1 and SC-1 are met by POL-01 as a whole.

Traceability for every statement is in `policy-control-map.csv`.
