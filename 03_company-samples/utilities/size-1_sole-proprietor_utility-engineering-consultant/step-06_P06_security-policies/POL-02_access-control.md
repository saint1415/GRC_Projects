At the Sole Proprietorship tier the business keeps **one** consolidated policy, because one person writes, follows, and checks it (`01_company-sizes/tier-project-scaling.csv`, t1 P06). This file is kept so the folder has the standard policy set names. It holds no separate rules.

**Where the access control rules are:**

- POL-01 section 7 (Access control): own accounts and no shared credentials (7.1), app-based MFA or security keys (7.2), password manager and no browser-saved passwords (7.3), standard daily laptop account (7.4), device lock (7.5), sealed emergency access codes (7.6), monthly sign-in, sharing, and advisory review (7.7), quarterly share review before client access verifications (7.8), Client B gateway rules (7.9).
- POL-01 sections 6.3 and 6.4: client approval before any helper sees client security information, and 24-hour notice when an authorized person no longer needs access (SSA-A (2) and (4)).
- SP 800-53 AC-1 and IA-1 are met by POL-01 as a whole.
