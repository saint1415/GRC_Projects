At the Sole Proprietorship tier the store keeps **one** consolidated policy, because one person writes, follows, and checks it (`01_company-sizes/tier-project-scaling.csv`, t1 P06). This file is kept so the folder has the standard policy set names. It holds no separate rules.

**Where the access control rules are:**

- POL-01 section 7 (Access, configuration, and the terminal): own accounts and a separate cashier-level POS user (7.1), MFA (7.2), passphrases and no vendor defaults (7.3), quarterly user and add-on review (7.4), device lock (7.5), emergency access (7.6), change log and monthly check (7.7), terminal records and daily inspection (7.8), network separation and Wi-Fi (7.9).
- POL-01 section 6.4: owner-started, watched remote support sessions.
- SP 800-53 AC-1 and IA-1 (policy and procedures) and PCI DSS 7.1 and 8.1 are met by POL-01 as a whole.

Traceability for every statement is in `policy-control-map.csv`.
